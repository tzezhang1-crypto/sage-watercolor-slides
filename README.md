# 鼠尾草綠水彩教學簡報

`sage-watercolor-slides` 是製作繁體中文圖片式教學簡報的 skill。以米白紙感、鼠尾草綠、柔和水彩插畫及指定文字圖例，建立清楚且一致的簡報。

完整執行規則以 [SKILL.md](SKILL.md) 為準。

## 工作流程

1. **讀完文件資料**：整理主題、受眾、重點與來源，不自行補造事實。
2. **給予建議頁數**：依資訊量及可讀性提出頁數與理由，說明是否包含封面、結尾。
3. **建立大綱**：列出每頁標題、核心訊息、預定文字及插圖配置。
4. **建立樣本待核准**：製作實際圖片式樣本，展示文字、配色及排版；收到使用者明確核准後才進入整份製作。
5. **建立整份圖片型 PPTX**：依核准樣本完成各頁，核對文字並微調一致性；最終 PPTX 每頁只放一張滿版高解析 PNG／JPEG，文字已烘焙在頁面圖片中，不保留可編輯文字框。同步交付依頁序命名的高解析頁面圖片及縮圖總覽，並在交付前完成逐頁視覺驗證。

## 文字規則

- 依 [文字圖例](assets/text-style-reference.jpg) 呈現圓潤筆畫、圓角收筆、舒展字面、近等粗線條及柔和淺綠。
- 原始字型名稱尚未確認，不臆稱已辨識原字型；若未提供原始字型檔，明確記錄為「視覺近似字型」。預設使用已驗證可用、具圓潤舒展 CJK 字形的 `Yu Gothic`；若使用者提供字型檔，優先採用該字型。使用簡報 API 時使用支援的 `typeface` 欄位，不以 `fontFamily` 代替。
- 圖片型 PPTX 的字體必須在頁面 PNG 渲染階段固定並烘焙，避免開啟端重新排版或替換字體；中文、英文及數字須維持一致的手繪教學視覺。
- 使用正確繁體中文，逐字檢查漏字、重字、假字、錯字、標點、數字及英文拼寫。
- 簡報文案來自文件與大綱；圖例示範字不會自動成為每頁內容。
- 若淺綠文字的投影對比不足，在樣本階段提供加深版本供核准。

## 背景圖例規則

- 背景圖例須配合該頁文字內容，協助解釋或呼應重點。
- 每頁背景插圖、人物與裝飾圖例的合計面積，**不得超過整頁的 1/3**。
- 以圖例配置外框計算，重疊部分不重複計入；純米白底色不計入。
- 不以透明像素或降低透明度規避面積限制，不遮擋文字或降低可讀性。
- 舊參考圖即使插畫較大，新製作頁面仍須遵守此上限。

## 視覺與版面

- 約 16:9 橫式，米白背景與鼠尾草綠主色，搭配少量淡金黃及珊瑚紅。
- 水彩插畫使用柔和細線，人物維持自然比例。
- 統一標題位置、字形、行距、人物比例與留白；內容過長時優先精簡或拆頁。
- 適用封面、條列步驟、雙欄比較、流程分鏡與結尾檢核頁。

## 使用方式

在可讀取此資料夾的 Codex 對話中，指定使用本資料夾的 `SKILL.md` 並提供文件、受眾與用途。例如：

> 請依這份 SKILL.md，閱讀我提供的文件，製作給初學者使用的教學簡報。先建議頁數、建立大綱，再做樣本給我核准。文字依附帶圖例，背景圖例須呼應內容且合計不超過版面的 1/3。

全域安裝位置為 `C:\Users\user\.codex\skills\sage-watercolor-slides`。安裝後可在其他專案中指定使用 `$sage-watercolor-slides`；本機來源與全域安裝副本分開保存，修改後需同步更新。

## 交付與檢查

預設交付圖片型 PPTX、依頁序命名的高解析圖片與整份縮圖總覽。圖片型 PPTX 每頁只包含一張與畫布等大的 PNG／JPEG，文字並非可編輯文字；不得把原始文字框、可編輯形狀或未烘焙文字留在最終交付檔。需要時可另輸出 PDF，但不得以 PDF 取代圖片型 PPTX 的驗證。

完成前逐頁核對文案、換行、裁切、背景圖例關聯及 1/3 面積上限，再用總覽比較風格一致性。製作整份前必須已有樣本核准；最終檢查須確認每頁只有一張滿版圖片、沒有可編輯文字框，並以 `textShapes: 0` 等檢查結果作為圖片型 PPTX 的結構驗證。
